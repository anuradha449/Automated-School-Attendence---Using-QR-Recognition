# 📖 Overview

The **QR Code Based Student Attendance Management System** is a smart web application designed to automate attendance management in educational institutions.

Instead of maintaining attendance manually, teachers can simply scan each student's QR code to mark attendance instantly. The system securely stores attendance records in a MySQL database and provides daily and monthly attendance reports.

This project improves accuracy, saves time, and eliminates paperwork.

# ⚙ Installation

## Step 1

Download and Install **XAMPP**

---

## Step 2

Clone the repository

```bash
git clone https://github.com/USERNAME/attendance-system.git
```

---

## Step 3

Move the project folder into

```text
C:\xampp\htdocs\
```

---

## Step 4

Start

- Apache
- MySQL

from XAMPP Control Panel.

---

## Step 5

Open

```text
http://localhost/phpmyadmin
```

Create a database named

```text
attendance_system
```

Import

```text
attendance_system.sql
```

---

## Step 6

Run

```text
http://localhost/attendance_full_project_final/login.php
```
